# Security Policy

## Reporting a Vulnerability

Please report vulnerabilities privately via GitHub Security Advisories ("Report a vulnerability") on the affected repository. **Never report security vulnerabilities in public issues.**

## Response Times

- We will acknowledge receipt of your vulnerability report within 5 business days.
- We will provide a status update within 14 days.

## Coordinated Disclosure

We practice coordinated disclosure. Please allow us time to investigate and patch the vulnerability before disclosing it publicly.

## Bug Bounty

We currently do not offer a bug bounty program.
